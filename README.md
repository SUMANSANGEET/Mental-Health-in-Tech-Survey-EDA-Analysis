# 📌 Project Overview

Mental health has become an increasingly important workplace and organizational-performance consideration, particularly within the technology sector.

This project analyzes **Mental Health in Tech Survey data** to understand:

* 🧠 Mental-health patterns among technology workers
* 🩺 Treatment-seeking behavior
* 🏥 Awareness of available care options
* 👨‍👩‍👧 Impact of family history
* 💼 Workplace and employment characteristics
* 📊 Demographic and behavioral patterns
* 📈 Changes between survey years
* 🤖 Predictive patterns using Machine Learning
* 💡 Business opportunities for improving workplace support

The project transforms raw survey responses into an **interactive analytics product** designed for business stakeholders, recruiters, analysts, HR teams, and decision-makers.

---

# 🎯 Business Problem

Organizations need better visibility into employee mental-health challenges and the factors that influence whether employees seek professional support.

The key business question is:

> **How can organizations use employee survey data to understand mental-health challenges, identify barriers to treatment, and design more effective workplace support programs?**

### Core analytical questions

| Business Question                       | Analytical Objective                             |
| --------------------------------------- | ------------------------------------------------ |
| 🧠 What mental-health patterns exist?   | Identify major behavioral and demographic trends |
| 🩺 Who seeks treatment?                 | Analyze treatment-seeking behavior               |
| 🏥 Are employees aware of care options? | Measure awareness and accessibility              |
| 👨‍👩‍👧 Does family history matter?    | Analyze relationship with treatment behavior     |
| 📅 Has the situation changed over time? | Compare survey years                             |
| 💼 What workplace factors matter?       | Identify organizational patterns                 |
| 🤖 Can behavior be predicted?           | Apply Machine Learning                           |
| 💡 What should organizations do?        | Translate analytics into recommendations         |

# 🩺 2. Treatment-Seeking Analysis

Understanding treatment-seeking behavior can help organizations improve:

* Employee assistance programs
* Mental-health benefits
* Awareness campaigns
* Confidential support channels
* Manager training
* Workplace communication

# 🏥 3. Awareness of Care Options

The project evaluates whether employees are aware of mental-health resources and care options.

### Why this matters

An organization can provide excellent mental-health resources, but the business impact may remain limited if employees:

> **Don't know that those resources exist.**

Therefore, awareness becomes an important component of workplace mental-health strategy.

# ⚙️ Installation & Local Setup

## 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Mental-Health-in-Tech-Survey-EDA-Analysis.git
```

## 2️⃣ Navigate to the project

```bash
cd Mental-Health-in-Tech-Survey-EDA-Analysis
```

## 3️⃣ Create a virtual environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### macOS / Linux

```bash
source venv/bin/activate
```

## 4️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

## 5️⃣ Launch Streamlit

```bash
streamlit run app.py
```

The application will open locally in your browser.
